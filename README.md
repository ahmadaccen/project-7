# Project 7 – CI Validation for Terraform

![Terraform Validation](https://github.com/ahmadaccen/project-7/actions/workflows/terraform.yml/badge.svg)

## Objective

Automate Infrastructure as Code (IaC) validation using GitHub Actions.

## Checks Performed

- Terraform Format Check (`terraform fmt`)
- Terraform Validation (`terraform validate`)

## Workflow

The GitHub Actions pipeline automatically runs whenever code is pushed to the repository.
